## ▶️ How to Use

Most of the projects are browser-based.

1. Clone the repository:

```bash
git clone https://github.com/AbrarJoo/Js.git
```

2. Open the repository in VS Code.

3. Open the required HTML file in a browser.

4. For a better development experience, use the **Live Server** extension in VS Code.

Some JavaScript files can also be run directly depending on what they contain.
